# Leonida Sirens — Hub

The public hub site for **Leonida Sirens**: GTA VI launch-week clips, original
merch collections and digital drops.

- Watch the Shorts and browse the catalog on the site.
- Every product page links out to the official store for checkout:
  https://leonidasirens-shop.fourthwall.com/
- Checkout, printing and shipping are handled by Fourthwall. This site takes
  no payments and collects no personal data.

Plain static site (HTML, CSS, JS — no build step), served with GitHub Pages.

Leonida Sirens designs are original artwork. Unofficial fan-made work; not
affiliated with, sponsored or endorsed by any video-game publisher or
developer.
